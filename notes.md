## Optimization

As this tool becomes more mature, the synthesis of the code can become a more intelligent and optimize process. Since the meaning of what is being synthesized is unambiguous, the synthesizer can reason about that meaning to choose the optimal implementation. 

## Security

There are also implications for security because the synthesizer is automatically aware of any vulnerabilities in the implementation. This isn't necessarily vulnerability in the design itself, it is in the actual mechanisms used in the programming language. The ability to fix such bugs automatically across all the implementaitons is a very powerful ability. 

The ability to synthesize the implementation from the meaning in this way means that gaining insight into the implementation itself is full automated. So any relevant analysis can be fully automated because it will be part of the construction process.
